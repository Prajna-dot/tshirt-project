# T-Shirt Project

## Project Overview

T-Shirt Project is a full-stack web application for browsing, managing, and purchasing T-shirts online. The application provides product management, user interaction, and order processing features.

## Objective

The objective of this project is to develop an e-commerce platform for T-shirt sales with a modern frontend and a robust backend.

## Technologies Used

### Frontend

* React.js
* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Other Tools

* Git
* GitHub
* REST APIs

## Features

* User Authentication
* Product Listing
* Product Details
* Shopping Cart
* Order Management
* Admin Product Management

## Installation

### Clone Repository

```bash
git clone https://github.com/Prajna-dot/tshirt-project.git
cd tshirt-project
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

## Running the Project

### Start Backend

```bash
cd backend
npm start
```

### Start Frontend

```bash
cd frontend
npm start
```

The application will run on:

```text
http://localhost:3000
```
